OPENLY ROTATION DASHBOARD UPDATE

INSTALL
1. Back up your local project and database.
2. Copy the src folder from this ZIP into F:\WebProj\openly, replacing matching files.
3. In Supabase SQL Editor, run 019_rotation_court_dashboard.sql AFTER migration 018.
   If you already ran 018 from the previous multi-court patch, DO NOT run it again.
   If 018 has not been applied, run the included 018 first (requires migrations through 017).
4. Run npm run build locally, then deploy your usual Vercel update.
The live database and website have not been changed by this package.

INCLUDED
This is a cumulative patch for your uploaded openly(1).rar, including the previous multi-court/trial changes.
- Host form requires rented court count; each court has its own Generate, Start and End round controls.
- Dark teal/lime dashboard with one shared waiting pool. No waiting-list shuffle or add-player controls.
- Initials represent real player names (no fabricated profile photos).
- Host-only settings and score controls; visitors cannot trigger premium redirects.
- Minutes / Round accepts 0 for no timer. Race to Points is numeric, default 11 (range 1-199).
- Settings may be changed before the first non-discarded round; then lock for consistent results.
- Social prioritizes fewer games and longer rest, then partner variety. Scores are optional.
- Competitive keeps fair turn priority and uses recorded results to balance the selected teams.
  This is session performance, not an official rating or strict skill bracket.
- Competitive: reach target with configured win-by, or finish on time. After timer expiry,
  finish the current rally, enter its score and choose Confirm timeout score.
  A lead is the final result; a tie shows Over time and exactly the next point wins.
  End round saves the submitted score and completion together, then releases that court's players.
- Completed matches appear in the existing Results tab; active players cannot be selected elsewhere.
- Optional championship and completed-score corrections remain available under collapsed sections.
  Championship/legacy shared rounds end as a shared round, as before.
- A confirmed timeout score is locked as the reference for its winner/overtime validation.
- Timer display is local; the server checks actual elapsed time. Keep the device clock accurate.
- First three published games include Smart Rotation via the earlier 018 migration.
